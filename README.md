# GemSpot KE

> **Discover Kenya's Best-Kept Secrets**
>
> GemSpot KE is a premium location discovery platform designed to help users find exceptional restaurants, cafés, nature destinations, nightlife venues, events, and adventure experiences across Kenya through an intelligent, visually immersive interface.

---

# Overview

GemSpot KE is more than a directory—it is a curated discovery platform.

Instead of overwhelming users with endless listings, GemSpot presents carefully selected places together with contextual information such as:

- Real crowd levels
- Budget expectations
- Parking availability
- Family friendliness
- Wi-Fi availability
- M-Pesa acceptance
- Live events
- Reviews
- Logistics
- Nearby attractions
- Curated recommendations

The application is built around the philosophy:

> **Less searching. Better decisions.**

---

# Installation

Clone the repository.

```bash
git clone https://github.com/yourusername/gemspot-ke.git
```

Navigate into the project.

```bash
cd gemspot-ke
```

Install dependencies.

```bash
npm install
```

Run the development server.

```bash
npm run dev
```

Open the application.

```
http://localhost:5173
```

---

# Build

Production build.

```bash
npm run build
```

Preview production build.

```bash
npm run preview
```
